# 🏥 Hospital Management System

A full-stack **Hospital Management System (HMS)** built using **React.js**, **Node.js (Express)**, and **MySQL**.  
This project streamlines hospital operations such as patient management, doctor scheduling, appointments, and much more — all through an easy-to-use web interface.

---

## 🚀 Features

### 👩‍⚕️ Doctor
- View assigned patients.
- Update diagnosis and prescriptions.
- Manage upcoming appointments.
- Access patient medical history.

### 🧑‍🤝‍🧑 Patient
- Register and log in to their account.
- Book and cancel appointments.
- View assigned doctors and treatment details.
